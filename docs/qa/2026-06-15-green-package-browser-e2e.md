## 本次发现并修复的问题

1. `/#worldcup-mode` 原来不会自动切换到世界杯专题。  
   修复：`static/js/nav-fix.js` 增加 hash 初始化与 `hashchange` 处理。

2. `worldcup.js` 如果在 DOM 已完成后加载，可能错过 `DOMContentLoaded` 初始化。  
   修复：增加 `initWorldCupManager()`，根据 `document.readyState` 决定立即初始化或等待 DOM 事件。

3. 内置浏览器环境下复制 API 可能不可用。  
   修复：`static/js/worldcup.js` 增加 `copyTextWithFallback()`，现代剪贴板失败时自动尝试旧式复制方法。

## 安全与边界确认

- 基础预测不依赖数据库。
- 基础预测不依赖 AI Key。
- AI 只解释已有概率，不参与概率计算。
- 导出内容不包含 API Key、数据库密码或 `.env` 信息。
- 未引入 Playwright / Selenium 等大型自动化依赖。
- 未实现 Phase C-E 功能。

## 非阻塞说明

- Codex 内置浏览器不支持捕获下载事件；本次以页面点击成功提示和结果保持可见作为验收依据。
- 打印窗口/系统打印对话框由浏览器处理，本次确认按钮点击后页面不崩溃、预测结果仍可见。
